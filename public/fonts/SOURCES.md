Self-hosted variable fonts from Google Fonts, distributed under the SIL Open Font License. See the adjacent OFL license files.

- DM Sans: https://github.com/google/fonts/tree/main/ofl/dmsans
- Manrope: https://github.com/google/fonts/tree/main/ofl/manrope

The binary font files are committed with the application and included in Vite's dist/fonts output, so deployment browsers do not need Google Fonts Internet access. They are unmodified upstream fonts.
